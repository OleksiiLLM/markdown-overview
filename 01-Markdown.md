# 1. Markdown

## What is it?
Markdown is a plain text formatting syntax and a software tool (originally written in Perl by John Gruber and Aaron Swartz in 2004) that converts plain text into structurally valid HTML.

## Design Goal
The overriding design goal of Markdown is **readability**. A Markdown-formatted document should be publishable as-is, as plain text, without looking like it has been marked up with tags or formatting instructions. Its syntax was heavily inspired by the conventions of plain text email.

## Why was it created?
It was created to give web writers an easy-to-read, easy-to-write plain text format that abstracts away the complexity and visual clutter of writing raw HTML.
